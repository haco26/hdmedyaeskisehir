# HD Medya — Statik yayın dosyaları

Bu klasör bilgiler.js ve src/site kaynaklarından otomatik oluşturulur. Ayar ve içerik düzenlemesi kaynak paketinde yapılmalıdır. Site PHP veya üretim sunucusu gerektirmez. Şemalar, iletişim ve temel metinler HTML içinde hazırdır.

Yayın için hazırlanan dosyalardır; bu revizyon hazırlanırken GitHub, Pages veya DNS üzerinde değişiklik yapılmamıştır.
